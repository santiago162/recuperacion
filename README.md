# Mokepon

Juego de batalla desarrollado con HTML, CSS y JavaScript. Elige un Mokepon, combate contra un oponente y usa ataques de agua, tierra y fuego para ganar.

## Cómo jugar

1. Abre `index.html` en un navegador.
2. Selecciona tu Mokepon y pulsa **¡Seleccionar y Batallar!**
3. Elige ataques hasta que termine el combate.

## Estructura del repositorio

- `index.html`: estructura de las pantallas del juego.
- `styles.css`: estilos y diseño adaptable.
- `js/mokepon.js`: selección de personajes y lógica de combate.
